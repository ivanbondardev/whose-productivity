# Сторінка книги

Статичний односторінковий сайт книги «Кому належить твоя продуктивність?» для GitHub Pages. Збірка, пакетний менеджер і серверна частина не потрібні.

## Поточна редакція

Сторінку синхронізовано з п’ятою редакцією: п’ять блоків, 12 глав. Підключений PDF містить 67 сторінок. Обкладинка на сторінці — зображення першої сторінки цього PDF.

Вебсторінка має власний візуальний стиль: теплий світлий фон, темний сливовий головний екран, персикові акценти, великі заголовки Georgia й текст Arial. Обкладинка зберігає оформлення книги. Три сценарії подано в тонованих картках, а практичний приклад — як робочу нотатку. Зовнішні шрифти та JavaScript не потрібні. Після головного екрана йде репліка з прологу та стислий переказ трьох альтернативних гілок глави 8. Посилання на повну сцену відкриває PDF на сторінці 40.

Зміст має п’ять розгортаних блоків із усіма 12 главами; вони працюють без JavaScript і доступні з клавіатури. Далі показано фрагмент умовного запису, авторський задум і спосіб створення книги з внутрішніх знань LLM. «Перший запис: 15 хвилин» подано як початок роботи з однією ситуацією, без обіцянки повного аудиту чи гарантованої зміни умов.

## Адреси

Canonical і social metadata використовують цю адресу. Репозиторій сайту — `ivanbondardev/whose-productivity`; папка `website/` має власну історію Git. Локальні правки з’являться на публічній сторінці після публікації через цей репозиторій.

## Оновлення наступної редакції

1. Замініть `assets/whose-productivity-ivan-bondar-ua.pdf`, зберігаючи назву файлу.
2. Звірте опис, кількість сторінок, перелік глав і формулювання практичного результату в `index.html` з новою книгою.
3. Оновіть зображення обкладинки з першої сторінки PDF і посилання на нього. У `width` та `height` вкажіть фактичні розміри зображення.
4. Оновіть параметр версії в обох посиланнях завантаження (`?v=5` для поточної редакції), щоб зменшити ризик отримання старого PDF з кешу.
5. Звірте номер сторінки в посиланні на переговорну сцену (`#page=40`) з новим PDF.
6. Перевірте розгортання змісту, локальні посилання, metadata та завантаження книги перед публікацією.

Текстова основа — `../book/00_front_matter.md`, `../book/00_editorial_bible.md` і поточний рукопис. Оновлення сайту не повинно повертати вилучені читацькі цитати, старі назви глав або автоматичні рекомендації за квадрантом.

## Публікація

Публікується вміст цієї папки в репозиторії `ivanbondardev/whose-productivity`. Для GitHub Pages використовується гілка й коренева папка, вибрані в **Settings → Pages**. Перевірте налаштування репозиторію перед зміною способу публікації.

Після публікації перевірте основну адресу й обидві кнопки завантаження. PDF і зображення обкладинки мають належати тій самій редакції.

## Локальний перегляд

Із папки `website/`:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Відкрийте `http://127.0.0.1:4173/`. Також можна відкрити `index.html` напряму.
